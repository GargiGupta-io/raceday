# Extension Icons

Required sizes: 16x16, 48x48, 128x128 (PNG format)

To generate from the RD logo:
1. Create a 128x128 red (#dc2626) rounded rectangle
2. Add white "RD" text in bold
3. Export at 128, 48, and 16px

For now, the extension will work without icons (Chrome shows a default puzzle piece).
